# IG Marketing Project Instructions

- Preserve original marketing photographs. Never use generative processing on
  uploaded animal photos.
- Maintain strict MAJOR.MINOR.PATCH application versioning.
- Treat each advertisement design as a versioned template with its own geometry,
  assets, defaults, and regression fixtures.
- Keep shared editor behavior reusable across templates.
- Validate at 720×1280 and at an iPhone-sized viewport before reporting a change
  complete.
- Do not commit, push, deploy, publish, or change repository visibility without
  the owner's explicit approval for that exact action.
- The repository may be public. Never add credentials, private URLs, personal
  data, or unapproved animal/business assets.
